Project title
Butterfly 

What and why?
What software system would you like to build this semester, and why? Include a description of what problem the system would solve and why this is important.
I want to build an IOS app for people with very strict diets such as vegan diets. I have had personal experiences with friends who have a very strict diet finding it difficult to enjoy a meal outside their home without having to do diligent research on the area they are going. Many restaurants advertise as vegetarian meals but this app will ONLY inlcude vegab resturatants or resturants that offer vegan options [not vegeterian].

For whom?
This will be for users who have severe allergies, or have a strict diet, like a vegan diet. 

How?
This app will work similar to google maps except the only options available will be vegan restaurants. It will have a regular user log in and account creation to track their personal restrictions. Users will only be able to view restaurants that are only vegan or that fit their dietary restrictions. The user will be able to leave reviews on restaurants or add new locations that include vegan options. Users will also have access to a AI chat that can answer any particular questions on menu options and whether it can potentially have ingredients the user has listed as restricted. 


Scope
The project may be tedious as we will be creation a user log in and account. We will also need to figure out how to filter out restaurants that have vegan options on their menu. Moreover, I want to implement an AI agent chat which will have more information on how to verify the meal is vegan friendly or not.
